# NURSEZIM_SHOP — Шағын онлайн дүкен

## 1. Жоба туралы

NURSEZIM_SHOP — HTML, CSS және JavaScript технологиялары арқылы жасалған шағын онлайн дүкеннің веб-сайты. Жобаның негізгі мақсаты — пайдаланушыларға тауарларды қарауға, іздеуге және себетке қосуға мүмкіндік беретін ыңғайлы веб-сайт құру.

Жоба 9-аптаның практикалық тапсырмасы аясында орындалды.

## 2. Жобаның мақсаты

- Онлайн дүкеннің веб-интерфейсін жасау.
- HTML арқылы сайт құрылымын құру.
- CSS көмегімен сайттың дизайнын жасау.
- JavaScript арқылы интерактивті функцияларды қосу.
- Тауарларды іздеу және санаттар бойынша сүзу.
- Тіркелу, жүйеге кіру және себет функцияларын іске асыру.

## 3. Қолданылған технологиялар

- HTML5 — веб-сайттың құрылымын жасау.
- CSS3 — сайттың дизайны мен адаптивті беттеуін жасау.
- JavaScript — интерактивті функцияларды іске асыру.
- LocalStorage — браузерде демонстрациялық деректерді сақтау.

## 4. Сайттың мүмкіндіктері

- Заманауи және ашық түстермен безендірілген дизайн.
- Тауарларды карточкалар арқылы көрсету.
- Тауарларды атауы бойынша іздеу.
- Санаттар бойынша сүзу.
- Тауарларды себетке қосу және өшіру.
- Себеттегі тауар санын өзгерту.
- Тіркелу және жүйеге кіру терезелері.
- Экран өлшеміне бейімделетін дизайн.
- Пайдаланушыға хабарламалар көрсету.

## 5. Жоба құрылымы

```text
NURSEZIM_SHOP/
├── index.html
├── style.css
├── script.js
└── README.md
```

Файлдардың қызметі:

- `index.html` — сайттың негізгі құрылымы.
- `style.css` — сайттың сыртқы көрінісі мен дизайны.
- `script.js` — сайттың интерактивті функциялары.
- `README.md` — жоба туралы ақпарат.

## 6. Жобаны іске қосу

1. Жоба файлдарын бір папкаға орналастыру.
2. `index.html` файлын браузер арқылы ашу.
3. Сайттың негізгі функцияларын тексеру.

Жобаны іске қосу үшін қосымша сервер орнату қажет емес.

## 7. 9-аптада орындалған жұмыс

9-аптада шағын онлайн дүкеннің веб-сайты жасалды. HTML арқылы сайттың құрылымы құрылып, CSS көмегімен безендірілді. JavaScript арқылы тауарларды іздеу, санаттар бойынша сүзу, себетке қосу және тіркелу интерфейсі сияқты функциялар жүзеге асырылды.

Жоба барысында веб-сайт құру, стильдермен жұмыс істеу және интерактивті элементтерді қолдану дағдылары жетілдірілді.
